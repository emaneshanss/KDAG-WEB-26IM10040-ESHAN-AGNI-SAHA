# KDAG Beginner's Python & Data Analytics Bootcamp Website

A responsive, multi-page website developed for the Kharagpur Data Analytics Group (KDAG) fresher's selection assignment. Built using vanilla HTML5, CSS3, and JavaScript.

## Project Overview

This project serves as a web portal for KDAG's Python & Data Analytics Bootcamp, featuring:
- A landing page (`index.html`) providing an overview of the program.
- A registration page (`register.html`) containing the applicant enrollment form.
- A dark-mode stylesheet (`styles.css`) for consistent site-wide branding.
- Validation logic (`script.js`) for error handling and input verification.

## Key Technical Features

- **Responsive Design:** Fits desktop and mobile viewports cleanly.
- **Client-Side Validation:** Ensures no required fields are submitted empty.
- **Roll Number Rule:** Strictly verifies the 9-character Roll Number format.
- **Dynamic Feedback:** Replaces the form with a success confirmation state upon valid submission
